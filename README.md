# SocialClubFrames Website

Responsive storefront for SocialClubFrames by Latoyya Smith.

## Main files
- `index.html` — website
- `assets/` — logo and responsive hero artwork
- `robots.txt` — search crawler rules
- `sitemap.xml` — search sitemap
- `manifest.webmanifest` — web app metadata
- `deploy-github-pages.ps1` — PowerShell deployment helper
- `GITHUB_PAGES_DEPLOYMENT.md` — complete deployment instructions

## Deployment
See `GITHUB_PAGES_DEPLOYMENT.md`.

## Checkout
The website is a browse-and-preview storefront. Purchases are completed through the SocialClubFrames Etsy shop.
